# GoldTransferMod

This is a mod for **Slay the Spire 2** that extends multiplayer shop logic with a gold transfer feature.


### Additional Info

A **Transfer** button appears in shops.  
After clicking it, you can choose an amount of gold and a teammate to transfer to.

Supports configuration via ModConfig:
- Default: free transfer
- If free transfer is disabled: one transfer per shop
- Optional fixed transfer amount: 50

ModConfig: https://github.com/xhyrzldf/ModConfig-STS2

这是一个用于 **杀戮尖塔2** 的 Mod，扩展了多人联机商店中的金币转账功能。


### 补充信息

在商店中会出现 **Transfer** 按钮。  
点击后可选择转账金币数量与目标队友，完成金币转移。

支持通过 ModConfig 配置：
- 默认可自由转账
- 关闭自由转账后，每个商店仅可转账一次
- 可设置固定转账额度为 50

ModConfig：https://github.com/xhyrzldf/ModConfig-STS2
